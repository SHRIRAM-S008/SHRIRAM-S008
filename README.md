### 🌾 AgriQPort

**Verifiable quality infrastructure for agricultural exports.**

AgriQPort explores how agricultural quality certifications can become **digital, verifiable credentials** rather than static documents.

**Core ideas**

- W3C Verifiable Credentials
- MOSIP Inji Certify
- Digital certification
- Supply-chain verification
- Issuer → Holder → Verifier workflows

### 🧰 GenRise Tools

**A privacy-first utility platform.**

A collection of useful browser-based tools designed around a simple principle:

> **Your data should stay where you use it.**

Tools are designed to perform processing locally in the browser whenever possible.

**Principles**

- Zero unnecessary uploads
- Browser-first processing
- Fast interactions
- Minimal infrastructure
- Privacy by design
